# 06 — Delayed effects, objectives, transformations (P5)

Status: open

Trigger-gated, incremental. Delayed effects: first establish whether Counters + duration systems suffice; if not, a small scheduled-consequence concept tied to engine boundaries — deterministic, replayable, visible in state, never wall-clock. Objectives: explicit encounter victory/defeat terms arrive with the first non-Boss-kill encounter rather than by growing checkResolution case by case. Transformations: identity-preserving state transitions where identity matters.
