# Deck Evaluation Notes

Use this directory for the human-scored side of deck evaluation. These notes are not in-game telemetry and do not create rules; they attach Design observations to Encounter Record evidence.

Filename convention:

```text
YYYY-MM-DD-<deck-slug>-<seed-set>.md
```

Example:

```text
2026-08-13-elian-voss-baseline.md
```
