# Paladin Placeholder Status

The original Paladin card-table concept from early prototype discussion is not yet stored as playable resources in this repository.

The current runnable player deck is [Elian Voss Starter Deck](D:/dev/webgame/docs/content/decks/elian-voss-starter.md), implemented as twenty `.tres` cards in `resources/cards/tank`. It is a tank-role stand-in and should remain the live demo deck until the Paladin list is deliberately authored, balanced, and migrated into card resources.
