# Design Decision Log

This log records current design-team decisions and recommendations. It does not replace ADRs; promote a decision to an ADR when it creates a long-lived architectural or product constraint.

**Adding a row: put `D-NEW` in the ID column and do not pick a number.** Run `cd web && npm run log:ids -- --fix` and the number is assigned against `origin/main` as it stands at that moment, and carried into any file on your branch that cites it. Picking a number by hand is what produced two D-045s, two D-046s, two D-047s and two D-057s: by the time a branch merges, the number it read is often gone. `npm run verify:local` refuses to pass while a row is unnumbered or holds a number `origin/main` has since taken.
