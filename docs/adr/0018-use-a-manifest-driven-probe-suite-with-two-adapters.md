# Use a manifest-driven Probe suite with two adapters

Probe registration lives in one data file, `scripts/debug/probes.manifest` (`lane|name|script|marker`), read by two thin runner adapters: `run_probes.sh` for POSIX machines and CI, and `run_probes.ps1` for the Windows authoring machine. A full run executes the `default` and `scenario` lanes and reports the skipped `manual` (needs a real window) and `tool` lanes, so bounded coverage is always visible. A Probe passes only when Godot exits `0`, its output contains the manifest's declared success marker, and no engine error or failed assertion appears — an exit code alone is not evidence that anything was asserted, and the adapters' fixture self-test keeps that enforcement honest.

The previous runner was a hand-maintained PowerShell hash: `-Probe all` ran twenty-one of forty-three probe scripts, the scenario catalog was excluded from `all`, eighteen probes were reachable only by hand-typed paths, and four of those had been broken for multiple design generations without anyone noticing — they referenced the Energy and Tempo systems removed by ADR 0011. Registration-by-omission is how probes rot silently. The manifest inverts the default: the `suite_manifest` Probe fails the suite whenever an executable probe script is missing from the manifest, a manifested script is missing from disk, or a declared marker is absent from its probe's source. Adding a probe now requires one manifest line, and forgetting it is a red suite, not a silent gap.

Alongside the migration, every previously orphaned probe was run and triaged: eleven were revived into the manifest (three needed small updates to current contracts), and the four dead-design probes were deleted per this harness's lifecycle rule rather than left to rot. New Probes extend the shared `ProbeCase` base — one accumulating assertion semantics, one marker/exit contract, one standard scene-free Encounter fixture — replacing the three incompatible assertion styles (accumulate, fail-fast, and engine `assert`, the last stripped in release builds) that had grown across hand-rolled probes.
