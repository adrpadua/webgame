# Put phase changes on the action stream

Every state change the phase machine causes rides a first-class `EncounterAction` on the engine's history stream: `ADVANCE_PHASE` (phase entry, and the window-flag lifecycle of the phase it leaves), `ROUND_START` (Round increment, armor reset, Status Effect rounds, Boss Program advance), `FULL_CHARGE_CLEANUP` (per Slot, recording the discarded Top Card and Charge Stack), `DRAW_CARD` and `SHUFFLE_DECK` (the Persistent Hand refill, with the drawn card recorded at resolution), and `END_OF_CLOCK` (Encounter Clock expiry defeat). `advance_phase` returns the complete ordered slice of actions it produced. Before this, only Status Effect expiry rode the stream; cleanup, draws, reshuffles, round rollover, and defeat-by-clock mutated silently, so history was an incomplete record and every observer had to poll fields or diff snapshots to reconstruct what the engine did.

Observers now fold the stream instead of guessing. The Encounter Record (schema 2) derives its phase boundaries from `ADVANCE_PHASE` and `END_OF_CLOCK` actions rather than polling round and phase fields, buckets phase-machine actions in a dedicated `phase_actions` list so submitted-action evidence stays player-shaped, and stamps each action with the round and phase current at its exact stream position. `PlayerState` folds the stream into consumed-once Slot transition cues, which deleted `ActionBarView`'s snapshot-diffing — presentation no longer re-detects a cleanup the engine already performed. Fold positions (history cursors) remain the pull-model mechanism by which observers track the stream; it is the polling and diffing that is gone.

Two boundaries are deliberate. Encounter setup — `start`'s board construction and the initial deck shuffle and draws — stays off the stream; the record's initial rules snapshot is the authoritative account of the starting state, and replay begins from it. And victory or defeat caused by damage stays attached to the causing action's Resolution Fact via the outcome fields; only clock expiry, which no action causes, is itself an action. The `action_stream` Probe protects the emission, ordering, payload enrichment, and presentation-fold contracts.
