# Make the rules board the only board authority

`engine.board` is the only board. `HexGrid` renders it — tiles, pieces, terrain, and telegraphs all derive from `sync_from_engine` — and answers view queries (movement cues, route previews) by delegating to `BoardQuery` over the rules board. The view owns no second `BoardState`, no scorched-terrain rule, no movement-legality fallback, and no mutation surface: `set_scorched`, `advance_board_state`, `is_scorched`, `spawn_enemy_wave`, `spawn_whelps_at`, `damage_enemy_front`, `move_piece_to`, `telegraph_hexes`, the spawn-candidate tables, and the pre-Encounter placeholder pieces are deleted.

Two parallel systems had answered the same questions. "Is this hex Scorched" had a rules answer (board Hazards) and a view answer (`HexGrid.board_state`); "can I move here" had `BoardQuery.is_legal_move` and a scene-graph fallback with its own occupancy and scorch checks; the Whelp spawn set was authored in three places. The view's answers fed real UI (tile drops, route arrows), so the two systems could disagree about the game being played. Alongside them sat a whole orphaned combat path — `BossActionData.resolve` mutating pieces through `HexPiece.take_damage` and grid spawn/damage helpers, plus the unreferenced `PlayerBoard` — with no callers; Boss behavior has resolved through the Boss Timeline since ADR 0007/0009. `BossActionData` survives as the authored-data schema for `resources/legacy/boss_actions` only.

The front cone is also one geometry now. The live `forward_cone` and the Target Pattern catalog's `FrontCone` disagreed — the live implementation produced an asymmetric wedge that included a distance-3 hex in a range-2 cone. `forward_cone` now shares the catalog's symmetric implementation, so Cinder Breath, telegraphs, and the acceptance catalog resolve identical hexes; the full probe suite, including the production-content Riposte path, holds under the corrected shape. The `board_authority` Probe protects the single-authority surface, the one-cone geometry, terrain rendering from rules Hazards, and the exact match between hand-card movement cues and the engine's legal moves.
