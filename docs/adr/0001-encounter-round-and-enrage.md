# Use a scripted two-window encounter round with an N-round enrage timer

The encounter will run on a mostly scripted `Boss Timeline` with an `Instant Row`, a shared simultaneous `Quick Window`, an `Incoming Row`, and a shared simultaneous `Slow Window`. We chose this over strict alternating turns because it better matches MMO raid callout play, supports 2-4 players without long downtime, and gives the boss a visible `N-round` enrage timer that can be tuned as the encounter's primary pacing constraint.
