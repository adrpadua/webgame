# Headless Rules SDK

The rules SDK is the scene-free starting point for Encounter mechanics. Its public seam is `EncounterEngine`:

```gdscript
engine.start(config)
engine.apply(action)
engine.advance_phase()
```

`start` creates the board, Heroes, Boss, Slots, and Boss Timeline. `apply` records and resolves one `EncounterAction`, including follow-up actions generated by cards, Boss Timeline beats, Status Effects, and Hazards. `advance_phase` resolves the current Boss Timeline row when appropriate and moves through `Instant`, `Quick`, `Incoming`, and `Slow`.

## Modules

| Module | Responsibility |
| --- | --- |
| `EncounterEngine` | Owns Encounter state, action history, phase advancement, and terminal resolution. |
| `EncounterAction` | First-class records for loading, charging, firing, moving, Boss resolution, hazards, Minion spawning, damage, and discarding for Stamina. |
| `ActionResolver` | Validates and applies action records, then emits follow-up records. |
| `TimelineResolver` | Turns authored Boss Timeline beats into damage, Hazard, and Minion actions. |
| `CardResolver` | Converts a Top Card and its Charge Stack into explicit resource and damage effects. |
| `BoardState` | Owns hexes, entity placement, terrain, and Hazards without a Godot scene. |
| `BoardQuery` | Provides hex-native pattern, radius, line, occupancy, Hazard, and legal-movement queries. |
| `StatusEffect` and `HazardEffect` | Provide explicit `on_round_start`, `on_enter_hex`, `on_damage_taken`, and `on_slot_fired` trigger behavior. |

The existing `Main`, `HexGrid`, `PlayerState`, and `BossState` remain legacy presentation-era code during migration. New encounter rules should enter through the SDK and its headless harness rather than adding resolution logic to a scene controller.

## Testing

Run the headless harness with Godot:

```powershell
godot --headless --path D:\dev\webgame -s res://scripts/debug/sdk_encounter_harness.gd
```

The harness builds Encounters directly, places combatants, applies action records, advances the Boss Timeline, and asserts board, card, Hazard, Status Effect, and end-of-round behavior without loading `Main.tscn`.
