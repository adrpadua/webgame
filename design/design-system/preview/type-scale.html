The 9/10/11 cluster is deliberate and is not a candidate for merging. Three sizes within three pixels looks like drift and is not: 9px is the demoted register, 10px the counted register, 11px the named register, each applied consistently. Collapsing them would be a redesign wearing a cleanup's clothes. An ESLint rule refuses a new arbitrary text-[Npx] outside the seven — this line already failed on documentation alone, which is why the padding rule needed a browser check too.
