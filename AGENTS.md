## Agent skills

### Issue tracker

Issues are tracked as local markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default mattpocock/skills label vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context domain doc layout. See `docs/agents/domain.md`.

### Engineering enablement

When reusable tooling, authoring or reporting contracts, probes, or cross-task delivery infrastructure spans roles, follow `docs/agents/engineering-enablement.md`.

### Playtesting

When a change makes a player-flow, input, mobile/responsive, accessibility, visual-hierarchy, or interaction-feel claim that needs independent hands-on evidence, follow `docs/agents/playtesting.md`.
