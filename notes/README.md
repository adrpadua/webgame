# Working Notes

This directory is for material that is useful during discovery but is not yet canonical:

- playtest observations
- screenshots and visual references
- research notes
- rough sketches and one-off investigations

When a note becomes a durable rule, decision, or content package, move its conclusion into `docs/rules/`, `docs/adr/`, or `docs/content/` and leave the original note here only when it still provides useful history.
