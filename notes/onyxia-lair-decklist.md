# Onyxia's Lair WoW TCG decklist notes

Date researched: 2026-08-13

## Source quality note

I could not access a first-party Upper Deck rules PDF directly from the web in this environment. The best accessible sources were:

- The archived `Onyxia Raid Deck Guide` page on Scribd for box contents and structure.
- The Trading Card Database checklist for the card names in the raid and event decks.
- Warcraft Wiki / Wowcards search snippets as cross-checks on the early card names.

## Structure

The 2006 `Onyxia's Lair` raid product includes:

- A 60-card Onyxia raid deck, described as `2 copies each of 30 different cards`.
- A 30-card event deck, described as `30 different cards`.
- 3 oversize Onyxia hero cards, one for each stage.
- 20 Whelp tokens.
